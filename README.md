# SmartBudgetManagger
A project for managing Budget.
Overview
SmartBudget Manager is an Excel workbook for tracking monthly income and expenses, organizing spending, and monitoring a budget.
Main Features
Record transactions; categorize expenses; calculate income, expenses, and balance; display charts; and warn when the budget limit is exceeded.
Requirements
Microsoft Excel 2016, 2019, 2021, Microsoft 365, or a compatible spreadsheet application.
Getting Started
1. Open SmartBudget_Manager.xlsx. 2. Go to Transactions. 3. Enter dates, descriptions, categories, income, and expenses. 4. Change the monthly budget limit in Dashboard cell B3 if needed. 5. Review the Dashboard and save with Ctrl+S.
Important Note
Enter accurate data and avoid changing formula cells. Keep a backup copy of the workbook.
